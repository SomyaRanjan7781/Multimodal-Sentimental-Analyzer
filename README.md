# Multimodal-Sentimental-Analyzer
It is a multimodal sentiment analyzer that detects the multimodal inputs from the user and predicts the sentiment of that in the form of positive , negative and neutral.
This project detects emotions from:

- Image (ResNet18)
- Audio (CNN + MFCC)
- Text (Sentence-BERT)
- Live Webcam

Technologies:
Python
PyTorch
Streamlit
Librosa
Sentence Transformers
